☁️ Sinkronisasi Cloud (Supabase)

Sinkronkan data otomatis ke cloud Supabase agar bisa diakses dari berbagai device (HP, tablet, laptop).

Status: —
Sync terakhir: Belum pernah
📖 Cara pakai di device lain

1. Buka file HTML ini di HP/tablet/PC lain

2. Login dengan akun yang sama

3. Buka menu Pengaturan → Sinkronisasi Cloud

4. Centang "Aktifkan Auto-Sync" → klik Download dari Cloud

5. Selesai! Data tersinkron otomatis antar device (real-time)

Catatan: setiap perubahan data di device A akan otomatis muncul di device B dalam ~1 detik (jika Real-time aktif).

URL: lvgpvcckwjllfmwglplb.supabase.co · Untuk migrasi dari schema lama, jalankan ulang supabase-schema.sql.

💾 Backup Otomatis ke Google Drive

Backup data secara berkala ke cloud storage pilihan Anda.

ℹ️ Status: Manual Export (recommended)

Saat ini backup dilakukan via Ekspor JSON (di section Backup & Restore atas). File JSON bisa Anda upload manual ke Google Drive/Dropbox Anda sendiri.

🚀 Setup Auto-Backup ke Google Drive (advanced)

1. Buka Google Cloud Console → buat project baru

2. Enable Google Drive API di APIs & Services → Library

3. Buat OAuth 2.0 Client ID (type: Web Application)

4. Tambahkan Authorized JavaScript origins: URL tempat aplikasi di-hosting

5. Dapatkan Client ID dari Google Cloud Console

6. Hubungkan dengan Google Identity Services (GIS) di JavaScript

Implementasi otomatis belum tersedia di versi ini. Untuk sementara, gunakan Ekspor JSON + Upload manual ke Drive.

Impor Massal dari CSV / Excel

Impor data setoran secara massal dari file CSV atau Excel (.xlsx). Format kolom harus: nama_hafiz, surah, ayat_from, ayat_to, juz, jenis, nilai, status, tanggal, catatan

Lihat contoh format CSV 
nama_hafiz,surah,ayat_from,ayat_to,juz,jenis,nilai,status,tanggal,catatan
Ahmad Fauzan,Al-Baqarah,1,5,1,Ziyadah,90,TY,2026-10-19,Lancar
Aisyah Nur Hidayah,Al-Kahf,1,10,15,Ziyadah,88,TY,2026-10-19,Hafalan kuat

Catatan: nama_hafiz harus sudah ada di Data Hafizh. Jika belum, akan dilewati. Surah dicocokkan berdasarkan nama (case-insensitive).

Tentang Aplikasi

Hifzhul Qur'an adalah aplikasi pencatatan setoran hapalan Al Qur'an yang dirancang untuk memudahkan ustadz/ustadzah, pembina halaqah, dan pesantren dalam memantau progress hapalan para santri/hafizh.

Seluruh data disimpan secara lokal di browser (localStorage), sehingga aplikasi tetap berfungsi tanpa koneksi internet dan tidak memerlukan server.

Versi 2.0 · Multi-Role (Admin, Pengajar, Siswa, Orang Tua) · Dibuat dengan niat untuk Allah SWT. Semoga menjadi amal jariyah.
